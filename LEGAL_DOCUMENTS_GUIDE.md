## Download Format Guide

### TXT (Plain Text)
- **Best for**: Editing in Word, Google Docs
- **File size**: Small
- **Editing**: Full control
- **Registration**: May need formatting for submission

### JSON (Structured Data)
- **Best for**: System integration, version control
- **File size**: Medium
- **Editing**: Technical use
- **Registration**: Convert to presentable format

### HTML (Formatted)
- **Best for**: Web viewing, screen reading, printing
- **File size**: Large
- **Editing**: Limited (use html editor)
- **Registration**: Print and submit physical copy

**Recommended Workflow:**
1. Download HTML to **view** the document
2. Download TXT to **edit** in Word
3. Download JSON to **store** in version control
